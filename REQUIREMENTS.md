# Requirements — Simple Counter

## What to build
A single-page web application that displays a counter and lets the user increment or reset it.

## Features
- Display a large number showing the current count, starting at 0
- An "Increment" button that increases the count by 1
- A "Reset" button that sets the count back to 0
- The count should update immediately when buttons are clicked

## Tech
- Plain HTML, CSS, JavaScript — no framework
- Single file output: index.html
- Must work in Chrome without any build step

## Acceptance criteria
- Count starts at 0 on page load
- Clicking Increment increases the count by exactly 1 each time
- Clicking Reset sets the count to 0
- The current count is visible and readable
- No console errors on load or interaction
- Page is usable on a mobile screen (375px wide)
